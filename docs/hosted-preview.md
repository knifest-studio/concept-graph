# Hosted interface preview

The private Sites preview serves the interface and a downloadable local helper. It is not a public release. The helper runs on the user's machine, uses their existing signed-in Codex CLI, and stores boards and original images in `~/.concept-graph`. Set `CONCEPT_GRAPH_DATA` before starting it to choose a different directory. Existing installations using `data/` are not migrated automatically; export and import a board or explicitly select the existing data directory while the old server is stopped.

Open the private Site, download the helper for your platform, extract the ZIP, and start the included launcher. The page recommends a matching build when the browser exposes the processor architecture, and otherwise asks the user to choose. It shows both ZIP download size and unpacked size; boards and images use additional space. The package includes its own Node.js runtime and dependencies; no separate Node.js or npm installation is needed. A compatible signed-in Codex CLI is still required. Keep the helper window open and enter the displayed pairing code on the page. The Apple Silicon Mac package has been tested locally; Intel Mac and Windows packages have not been tested on those platforms. The operating system may warn about an unidentified developer.

The helper listens on loopback port 43170 and only allows the configured Site origin with a per-launch pairing code. Closing the helper ends access. The Site's JavaScript can read and change paired local boards and images: trust the Site and keep its source and deployment secure. Browser local-network permissions may be needed.

To build the interface, run `npm run build:site`. To add the portable helper packages, set `CONCEPT_GRAPH_NODE_ARCHIVES` to a directory containing the Node.js archives listed in `scripts/build-portable-helper.mjs`, then run `node scripts/build-portable-helper.mjs`. The script verifies their pinned SHA-256 checksums and writes split downloads and their manifest alongside the interface. The output is written to `dist/`; set `CONCEPT_GRAPH_SITE_OUTPUT` to use a separate build directory. Site hosting configuration is in `.openai/hosting.json`.

OpenAI's app-server documentation says its authentication has not been permitted for commercial or hosted services, while existing local or open-source applications may continue to use it. Whether a hosted interface paired with a locally running open-source helper falls within that distinction is unresolved. Obtain clarification before offering the hosted integration publicly. See <https://learn.chatgpt.com/docs/app-server#auth-endpoints>.
